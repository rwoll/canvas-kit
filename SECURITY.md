# Security

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Do not open a public
issue. You can expect a reply within a few days.

Reports about the canvas server (`@rwoll/canvas-kit/server`), the release
workflows, the published `stable` marketplace branch, or the npm packages are
all in scope.

## Supported versions

Only the latest release of `@rwoll/canvas-kit` and `@rwoll/create-canvas`, and
the current `stable` branch, get fixes.
