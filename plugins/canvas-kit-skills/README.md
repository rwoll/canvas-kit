# canvas-kit-skills

Skills that teach Copilot agents to build, test, and publish canvases with
[@rwoll/canvas-kit](../../packages/canvas-kit/README.md).

```sh
copilot plugin marketplace add rwoll/canvas-kit#stable
copilot plugin install canvas-kit-skills@canvas-kit
```

| Skill | Use it to |
| --- | --- |
| [`canvas-kit`](skills/canvas-kit/SKILL.md) | Scaffold a canvas, define state and actions, and build its React UI |
| [`canvas-kit-testing`](skills/canvas-kit-testing/SKILL.md) | Write unit tests and Playwright browser tests |
| [`canvas-kit-publishing`](skills/canvas-kit-publishing/SKILL.md) | Publish a marketplace with GitHub Actions and update installs |
